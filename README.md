# Employee Recognition Hub

An AI-assisted web platform that centralizes multiple employee recognition programs into a single searchable interface, with guided award recommendations, eligibility rules, deadlines, and nomination guidance.

## Features
- Searchable directory of recognition programs
- Guided recommendations based on eligibility rules
- Deadline and nomination guidance built in

## Tech stack
HTML, CSS, JavaScript — built with the help of Claude and Microsoft Copilot

**Live demo:** https://kewuser.github.io/employee-recognition-hub/
